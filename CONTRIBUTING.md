# Contributing

## Add an agent integration

1. Link the agent's primary configuration documentation and the relevant Muapi setup page.
2. Record the exact API protocol, base URL, authentication method, and whether tool calling is required.
3. Use a live model ID and confirm its current tool capability before publishing a configuration example.
4. Label setup as documented until a real agent/model tool round trip has been completed. For tested entries, include app version, model ID, date, task, and result.
5. Keep safety controls and usage costs visible. Never include real API keys, harmful tasks, or fabricated success claims.

## Claims and scope

“Uncensored” is an informal community label, not a guarantee. Distinguish a model's API capability from the agent's permissions. This catalog covers general-purpose agents and their hosted model connections; coding IDE and terminal agent benchmarks belong in the companion `uncensored-coding-models` repository.
